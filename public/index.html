POST /api/send

Send an email using SMTP configuration.

Request Body
{
  "config": {
    "host": "smtp.example.com",
    "port": 587,
    "secure": false,
    "auth": {
      "user": "your-email@example.com",
      "pass": "your-password"
    }
  },
  "data": {
    "to": "recipient@example.com",
    "subject": "Test Subject",
    "html": "
Test HTML content
",
    "autoresponse": {
      "enabled": false,
      "content": "Optional autoresponse content"
    }
  }
}
Response

Success: { "status": "success", "messageId": "..." }

Error: { "status": "error", "message": "..." }
